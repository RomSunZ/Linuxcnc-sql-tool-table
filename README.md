<h2><strong>Расширенная таблица инструментов для Linuxcnc QtDragon на SQLite.</strong></h2>
<p>Для корректной работы сделать скрипт исполняемым: chmod +x tool_db_daemon.py<br />
Переименована колонка Diameter на D Wear и используется в качестве компенсации износа инструмента.<br />
Добавлены колонки:</p>
<ul>
	<li>R (колонка Diameter) - диаметр инструмента</li>
	<li>H (колонка Heavy) - тяжелый инструмент (например для снижения скорости при смене)</li>
	<li>L (колонка Large) - большой инструмент (например занимает две соседние ячейки)</li>
	<li>S (колонка Runtime) - время наработки инструмента по G1/G2/G3 и при включенном шпинделе</li>
</ul>
<p>Для RANDOM_TOOL_CHANGER = 0 колонка Pocket не имеет значения и скрыта.</p>
