Расширенная таблица инструментов для Linuxcnc QtDragon на mysql.
Для корректной работы сделать скрипт исполняемым: chmod +x tool_db_daemon.py
Переименована колонка Diameter на D Wear и используется в качестве компенсации износа инструмента.
Добавлены колонки:
  R (колонка Diameter) - диаметр инструмента
  H (колонка Heavy) - тяжелый инструмент (например для снижения скорости при смене)
  L (колонка Large) - большой инструмент (например занимает две соседние ячейки)
  S (колонка Runtime) - время наработки инструмента по G1/G2/G3 и включенном шпинделе
Для RANDOM_TOOL_CHANGER = 0 колонка Pocket не имеет значения и скрыта.
